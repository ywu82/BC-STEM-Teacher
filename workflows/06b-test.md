# Step 6B — Final unit test

## Trigger and outcome

Run after instruction when the teacher requests a broader summative assessment. Require approved objectives and created or imported instructional materials; otherwise label the blueprint provisional. Produce separate student and teacher HTML files, or one verified package containing both.

## Procedure

1. Build an OID × material ID × construct × cognitive demand × points blueprint using `templates/assessment-blueprint.md`.
2. Sample required objectives sufficiently across suitable item formats, including transfer or integration where valid.
3. Keep answers, scoring guidance, and rubrics in the teacher file only.
4. Verify solutions, point totals, time feasibility, objective coverage, accessibility, approved accommodations, and applicable science safety requirements.
5. Do not claim that a format measures an objective it cannot validly demonstrate; use performance or observation evidence where needed.

## Persistence

Register the test ID, branch `6B`, artifact paths, blueprint, OIDs, maximum score, language, and approval status in the project manifest.

## Done

Step 6B is complete when the test package, answer/rubric, blueprint, validation, and teacher approval are recorded. Step 6A and Step 6B are independent branches unless the teacher requests both.
