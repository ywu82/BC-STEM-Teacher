# 04 Diagnostic quiz (BEFORE teaching; independent branch)
Do not base diagnostic questions on newly generated slides unless the point is a preexisting skill. Read approved objectives and prerequisite map. Create short, low-stakes, predominantly foundation-level D1...Dn, answer key, reason for each distractor, misconceptions-to-remediation lookup, zero-pressure instructions. Link each item to a prerequisite and future objective; define no-grade policy. No un-taught jargon or hidden multi-step novelty that distorts readiness. Results guide teaching adaptations; do not label students fixed ability groups.
