# Step 2 — Develop course-level learning objectives

## Trigger

Run after Step 1 has one teacher-approved exact course.

## Required input

Use verified curriculum sources, teacher-entered objectives, or an accessible uploaded source document. If none is available, offer provisional draft objectives and label them clearly.

## Procedure

1. Extract or draft objectives only from sources that are actually accessible.
2. Show extracted statements before refinement and distinguish official, teacher-provided, and AI-proposed wording.
3. Normalize the objectives into stable OIDs with observable actions, success criteria, prerequisites, evidence types, and provenance using `templates/objectives.md`.
4. Check that the set is coherent for the approved course and does not claim unverified provincial alignment.
5. Ask the teacher to approve or revise the objective set.

## Persistence

Save the objectives, provenance, verification status, and approval status in the project manifest.

## Done

Step 2 is complete when every course-level objective has an OID, measurable evidence criterion, source status, and teacher approval. Advance to **Step 3 — Select the teaching scope**.
