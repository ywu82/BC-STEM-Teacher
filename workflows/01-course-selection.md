# Step 1 — Select and confirm the exact course

## Trigger

Start here for a new project, or return here when the teacher changes the subject, grade, or course.

## Required input

- subject area;
- grade;
- exact BC course name when known.

## Procedure

1. Resolve the request to one exact BC Grades 10–12 course. Use `subjects/` for navigation and `references/course-verification.md` for official-source verification.
2. Record whether the course and curriculum source are `VERIFIED` or `PROVISIONAL`. Never treat a teacher label or uploaded objective list as official Ministry wording without verification.
3. Show the selected course, jurisdiction, grade, source URL, access date, and any remaining ambiguity.
4. Ask the teacher to approve the exact course before developing course-level objectives.

## Persistence

Save the course fields, source provenance, curriculum status, and approval state in `templates/project-manifest.json`.

## Done

Step 1 is complete only when one exact course is recorded and teacher-approved, with its verification status stated. Advance to **Step 2 — Develop course-level learning objectives**.
