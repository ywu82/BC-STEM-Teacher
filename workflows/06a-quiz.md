# Step 6A — Post-instruction quiz

## Trigger and outcome

Run after instruction when the teacher requests a short, low-stakes check. Require approved objectives and created or imported instructional materials; otherwise label the blueprint provisional. Produce separate student and teacher HTML files, or one verified package containing both.

## Procedure

1. Build an OID × material ID × construct × cognitive demand × points blueprint using `templates/assessment-blueprint.md`.
2. Sample the targeted taught content with prompt wording and accessibility appropriate to the course.
3. Keep answers, scoring guidance, and distractor rationales in the teacher file only.
4. Check every answer, point total, objective mapping, approved accommodation, and applicable science safety requirement.
5. Provide a prompt feedback/correction route appropriate to a quiz.

## Persistence

Register the quiz ID, branch `6A`, artifact paths, blueprint, OIDs, maximum score, language, and approval status in the project manifest.

## Done

Step 6A is complete when the quiz package, answer/rubric, blueprint, validation, and teacher approval are recorded. Step 6B is a separate branch, not a required continuation of 6A.
