# Student Learning Evidence Report
The primary teacher deliverable is one self-contained English file: `teacher_report.html`. It must open directly to the course context, provenance badge, instructional priority, assessment summary, objective attainment table and interactive radar, teaching recommendations, warnings and interpretation limits. Technical artifacts (`report.json`, `summary.md`, CSV inputs and separate SVG/HTML charts) remain available for audit or fallback but are not presented as equal teacher-facing choices.

The agent must also present a compact in-chat evidence brief in the teacher's current language. It includes: course/provenance; one-sentence instructional priority; an assessment table with complete/partial/missing and highest/lowest/mean/median; a latest-assessment objective table with observed %, local target and target-attainment count; the latest-assessment radar chart displayed directly in chat; 2–4 evidence-linked next teaching moves; missingness/error-pattern uncertainty and no-growth caveats; and one link to `teacher_report.html`. Use an interactive chat radar when supported, otherwise display or attach the verified static radar image. The HTML expands the conversation; it does not replace it.

Course, OIDs, reporting period, assessment population and missingness. Status of official curriculum alignment and data quality. Summary by assessment must include complete/partial/missing counts and the highest, lowest, mean and median percentage among complete responses. Include OID objective attainment (`earned/possible`, score percent and criterion flag), diagnostic prerequisite readiness and a separate evidence-linked teaching-recommendations section. Include accessible chart descriptions and exact denominators. Prefer a chat-native interactive radar when supported; otherwise deliver the complete HTML report as the primary portable artifact. If scores were not psychometrically comparable, say **NO COMPARABLE GROWTH ESTIMATE**. Clearly separate teaching recommendations from measured observations. Protect small-group confidentiality in anything publicly shared. No automatic official gradebook entries.
