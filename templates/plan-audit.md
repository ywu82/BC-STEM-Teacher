# Plan audit

Keep the teacher-facing audit concise and decision-led.

Write the audit in English by default. Use another language only when the user explicitly names that language.

1. Show one English verdict at the top:
   - `Revision Recommended` in orange/yellow when required content, alignment, evidence, pacing, accommodations, or feedback is missing.
   - `Ready to Use` in green only when the plan is sufficiently complete for the next workflow step.
2. State explicitly whether the plan can proceed to the next step.
3. Include a compact objective-alignment table using the required 0/1/2 coverage judgment; group objectives when that improves readability.
4. When the verdict is `Revision Recommended`, highlight only the required changes and give a clear `Why` for each change.
5. Omit nonessential narrative. Retain only the verdict, concise alignment evidence, required changes with reasons, the decision rule, and provenance/limits.
6. Always preserve the imported plan and propose diffs; do not replace it or advance the project stage without teacher approval.
