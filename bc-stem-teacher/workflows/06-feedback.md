# 06 Results → evidence → actions
Intake anonymized student×item points and item blueprint with OIDs. Reject invalid types, duplicate rows, negative/over-max scores, unknown OIDs and denominator=0. Include missingness separately. Produce sample size, distributions, per-objective earned/possible percentages, shares above teacher-defined targets, diagnostic prerequisite flags, quiz/test attainment, student-level privacy-safe actions, next lesson changes, matched-item caveats, interpretation limits. Charts: assessment mean, objective attainment side by side, percent attainment distribution; label numerator/denominator. Never make causal effectiveness claims based only on observational assessment. Use `scripts/analyze_results.py` when executable, otherwise return data and chart specifications rather than pretending plots exist.
