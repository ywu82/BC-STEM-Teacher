# Distinguish three assessment instruments
| | Diagnostic (D) | Teaching-material Quiz (Q) | Teaching-material Test (T) |
|---|---|---|---|
| Timing | Before teaching | During/after instruction | After unit/major sequence |
| Purpose | Prerequisites and misconceptions | Learning check against taught objectives | Wider/robust evidence of taught objectives |
| Source | Goals' prerequisite map + existing knowledge | Supplied/generated **taught** slides/content + objectives | Taught materials + curriculum objectives + blueprint |
| Difficulty | Predominantly recall/basic application; include a few probes | Mixed basic/apply/reason | Balanced/more transfer, integration and application |
| Stakes | Low/no grade | Low/formative by default | Teacher-defined; not automatically summative |
| Feedback | Readiness groups, reteach prerequisites | Misconceptions, slide-specific remedial activity | Per-objective evidence, next steps and possible re-assessment |

**Difficulty is not determined by labels alone**: judge actual prerequisite load, reading burden, steps, unfamiliar contexts and cognitive level, not raw percent correct. Do not force all diagnostic items to be trivially easy. Develop a blueprint BEFORE writing items; represent OIDs, item cognitive level, points and slide/source IDs. Check the actual correctness and unbiased accessibility of questions and answers. Ideally use anchor tasks measuring genuinely comparable constructs for a pre/post trend; reporting script is conservative even if comparable_group is supplied.

Do not mix pre-test percentages and post-test percentages as a single 'growth %' just because both are percentages. An honest side-by-side chart is not causal evidence that the lesson caused the difference.
